Database editor

Directly add, modify, or delete a BaseStation.sqb entry — e.g. when you already know an unlogged plane's registration and type. This is separate from the watchlist above and takes effect immediately, no Apply needed. Use the search tool's Edit button to load an existing entry here, or fill in an ICAO24 that isn't in the database yet to add one.

Registration backfill

Fills in missing registrations and aircraft types in BaseStation.sqb from a daily-updated copy of the tar1090-db aircraft database — only for aircraft that have been logged, and only where the field is still empty. Existing values are never changed; where one differs from tar1090-db it's listed below for you to check. Runs automatically every day at 04:30 UTC.
